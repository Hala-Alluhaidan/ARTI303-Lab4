Lab 4 - Task 1: Unification Queries


1. Query:
15 ?- house = house.
true.

Explanation:
The terms unify because both are the same atom.


2. Query:
16 ?- house = abc.
false.

Explanation:
The terms cannot unify because house and abc are different atoms.


3. Query:
17 ?- edge(a,b) = edge(C,b).
C = a.

Explanation:
The terms unify when C is assigned the value a.


4. Query:
18 ?- edge(a,d) = edge(C,B).
C = a,
B = d.

Explanation:
The terms unify when C is assigned a and B is assigned d.


5. Query:
19 ?- edge(C,B) = edge(a,d).
C = a,
B = d.

Explanation:
The terms unify when C is assigned a and B is assigned d.


6. Query:
20 ?- edge(A,f(g,h)) = edge(a,B).
A = a,
B = f(g, h).

Explanation:
The terms unify when A is assigned a and B is assigned f(g,h).


7. Query:
21 ?- edge(A,A) = edge(b,c).
false.

Explanation:
The terms cannot unify because A would have to be both b and c at the same time.


8. Query:
22 ?- edge(A,A) = edge(b,b).
A = b.

Explanation:
The terms unify because both occurrences of A can be assigned the same value, b.


9. Query:
23 ?- A = B, B = f.
A = B, B = f.

Explanation:
The terms unify because A and B are linked, and B is assigned the value f.


10. Query:
24 ?- A = B, B = f, A = e.
false.

Explanation:
The terms cannot unify because A and B become f, but the final condition requires A to be e.
